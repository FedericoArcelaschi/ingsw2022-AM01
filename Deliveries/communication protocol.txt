Comunication Protocol:

+---------------+												+---------------+
|Client			|												|Server			|
+---------------+												+---------------+
		|																| SERVER IS LISTENING on PORT ????
		|																|
		|																|
		|	*FIRST MESSAGE*												|
		|	------------------------------------------------------->	| Replies to the first message, opens the Socket and assigns
		|	<-------------------------------------------------------	| a unique ID to the client.
		|																|
		|																|
		|																|
		|													  *PING*	|
		|	<-------------------------------------------------------	| Heartbeat protocol:
		|	*PONG*														| Every 10 seconds, the server sends a Ping message to the client
		|	------------------------------------------------------->	| and waits for a Pong message. If the server doesn't receive a Pong message within
		|												*DISCONNECT*	| 10 seconds a disconnect message will be sent.
		|	< - - - - - - - - - - - - - - - - - - - - - - - - - - - 	|
		|																|
		|																|
		|																|
		|								    *GAME BEGINS (broadcast)* 	| In case there is a game a player can join,
		|	<-------------------------------------------------------	| the user is matched with the other players and
		|	<-------------------------------------------------------	| the game view is sent to every player involved.
		|																|
		|																|
		|											*ACTION TO MAKE*	| When it becomes his turn, the player is sent a prompt that
		|	<-------------------------------------------------------	| invites him to take an action.
		|																|
		|																|
		|																|
		|																|
		|	*LEGAL ACTION*												|
		|	------------------------------------------------------->	| The server receives a legal command from the client.
		|								*UPDATE TO VIEW (broadcast)*	| The server updates the model and each time it sends
		|	<-------------------------------------------------------	| the updated view to all the clients in the game.
		|	<-------------------------------------------------------	|
		|																|
		|																|
		|																|
		|	*ILLEGAL ACTION*											| In case a player sends an illegal move we don't update the model
		|	------------------------------------------------------->	| and the server sends only to him an error message.
		|											 *ERROR MESSAGE*	| Because the game has predefined turns and phases we'll wait for
		|	< - - - - - - - - - - - - - - - - - - - - - - - - - - - 	| each player to send a legal action before we can proceed with the
		|																| gameplay.
